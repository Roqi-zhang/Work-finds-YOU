## 三、三版设计思路（同一流程、同一数据，只改界面组织方式）

1. 方向一 · 求职日记本：每页像一页日记，左边是日期和页码，正文纵向书写；AI 判断写成"批注"，来源以脚注形式出现在页面边缘。最贴近当前气质。
2. 方向二 · 决策桌面：左右两栏，左栏固定画像（能力花缩小版 + 待补充项），右栏是岗位与分析；比较页为左右并排的两张"纸"，差异用手绘圈注标出。
3. 方向三 · 证据板：以"判断 → 证据 → 来源"三列表格化呈现，文字最大程度可视化（细线条形刻度、方括号状态、一句话结论在顶），信息密度最高、最利于对比阅读。

## 四、每版包含的页面

- A1 上传简历（拖拽/点选）
- A2 提取结果核对与编辑
- A3 1–2 个补充问题（可跳过）+ 画像摘要（标"待补充"）
- B 画像确认 + 多岗位输入（文本/链接/文件，可添加多个，显示每个输入状态，一个"开始分析"按钮）
- E1 分析中：解析岗位 → 寻找公开资料 → 结合画像分析，三段进度可展开
- E2 异常态：资料不足（不显示精确分数）、链接失效、分析失败，均有重试
- C 单岗位分析：一句话结论 → 匹配度与依据/未知项 → 公司做什么/岗位做什么/核心能力 → 匹配点/差距/无法判断 → 准备建议 → 来源区；底部「决定投递 / 暂不投递 / 待定」+ 可选原因
- D 两岗位对比：职责、核心要求、个人证据、待补充、城市偏好、影响优先级的差异；不自动排序；每列有"查看详情"和三个决策按钮
- 决策后提示进入现有投递管理（只做跳转，不重新设计）

共 3 版 × 9 屏。
