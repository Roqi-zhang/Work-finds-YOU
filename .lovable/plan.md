# 全站 UI 视觉优化方案

## 0. 前置约定

- **不动**：路由、功能入口、页面跳转、数据模型、组件的产品语义（导航项、按钮触发的动作、下一步/返回、状态标签的含义）。
- **可动**：布局、排版、色彩、字重字号、动效、图形化程度、留白节奏、加载态与空态、组件视觉。
- **锁定 Style DNA**（3 个方向共享，避免走偏）：
  - 配色：`#F1F1F1` 米白底 / `#404040` 深灰主字 / `#D4D4D4` 淡灰线，仅在极少数强调处允许纯黑 `#0A0A0A`。禁用彩色，禁用紫蓝渐变。
  - 字体：西文 Neue Haas Grotesk / Inter Tight，中文思源黑体或 HarmonyOS Sans，标题超大字号 + 极紧字距（-0.02em），正文 14px/1.7。
  - 线宽：0.5px 极细线主导，1px 仅用于当前态/hover。
  - 圆形语言：所有 loading、状态点、匹配点均使用「圆 / 月相」几何，禁用条状 spinner。
  - 动效：慢速 (400–800ms) `cubic-bezier(.2,.7,.2,1)`，禁用弹跳。
- **全局新增（共享）**：
  - 顶部/侧边「半圆表盘导航」：随页面滚动或路由切换，表盘像时钟一样旋转到对应刻度（01 开始 / 02 画像 / 03 匹配 / 04 对比 / 05 投递）。
  - 全局 Loading：月相圆点序列（O ◐ ● ◑ O）不同频次呼吸；备用款：水平线上的圆左右倾倒。
  - 空态：不再用「空框 + 按钮」，改为一句大字标题 + 极细线 + 单个圆点动作入口。

## 1. 首页 `/`

现状：左标题右卡片列表，底部三个说明卡，功能入口 = "开始分析" + 右侧 4 个导航项 + 底部 tab bar。三个方向都保留这些入口。

### 方向 A — 表盘首页（Dial Home）

- 左上大标题改成「Work Finds You」，字号放大到 96/104px，字重 500。
- 大标题下方加一个小标题「选对方向，工作找你」，要求中英文
- 右侧原卡片列表替换为**半圆表盘**：5 个刻度（01–05）沿弧线排布，对应 5 个入口；hover 刻度时表盘轻微旋转 8°，中心显示该模块一句话说明。
- "开始分析" 按钮变为表盘中心的圆形 CTA（细线圆 + 内文字，hover 填充深灰）。
- 底部三段说明卡去掉描边，改为三栏无框排版 + 序号 01/02/03，栏间只有 0.5px 竖线。

### 方向 B — 编辑排版首页（Editorial）

- 参考 A24 "HOW THIS WORKS" 与 "First you don't talk about design"：把主标题拆行占满 12 栏，字号 160px+，字距 -0.03em。
- 右上「AI 求职决策工作台」小 caption + 日期戳 `#2026·07·12` 作为编辑感元数据。
- 4 个导航项改为**编号目录**（01 CANDIDATE / 02 MATCH / 03 COMPARE / 04 DELIVERY），行高 72px，左右两端对齐，行间 0.5px 细线。
- CTA 改为一行下划线文字链接「开始分析 →」，不使用色块按钮。
- 底部三段说明改为跨栏杂志式布局（60/40 不对称栏）。

### 方向 C — 网格致密首页（Swiss Grid）

- 严格 12 栏栅格显形（0.5px 网格线常驻，浅到 4% 不透明度）。
- 左 4 栏放标题 + 描述 + CTA；右 8 栏放**四象限模块图**：4 个等大方块分别代表 画像 / 匹配 / 对比 / 投递，每块内嵌一张缩略示意（半圆表盘 / 能力花瓣 / 轨道图 / 智能表格）。
- 点击象限 = 原有跳转。hover 时该象限外框描 1px 深灰，其余淡出到 40%。
- 顶部通栏 marquee：滚动展示核心数据（"平均决策时间 ↓ 62%" 之类），提供密度感。

## 2. 画像页 `/onboarding`

现状：单张卡片「拖拽上传简历 / 手动填写」+ 返回 / 下一步。功能入口保留。

### 方向 A — 花瓣能力盘（Petal Model）

- 上传完成后立即渲染 refer.pdf 中的**花瓣能力模型**：5 专业 + 3 通用 + 2 偏好 = 10 花瓣绕中心圆排布，每片花瓣内写维度名 + 分数。
- 上传前：中心是虚线花瓣 outline + 中间圆形上传区（拖拽命中时花瓣依次点亮）。
- 手动填写切换为右侧滑出的抽屉，不打断花瓣视图。

### 方向 B — 分栏档案（Editorial Profile）

- 参考 "First you don't talk about design" 与 "Experiences"：左栏姓名 / 头像占位 / 一句自我描述（大字），右栏是分区块的能力/经历/偏好清单，块与块之间只用 0.5px 线分隔。
- 上传入口收窄为顶部一条「Drop CV here — or type manually」的横条，命中后转成进度条圆点序列。
- 底部大字统计带：「2m+ words parsed / 11+ roles / 58% match ready」——用假数据营造编辑质感。

### 方向 C — 卡片矩阵（Card Matrix）

- 参考 DOUBTS 杂志网格：把能力/经历/偏好拆成 9–12 个不等大卡片拼合，卡片内容混合（大字标签、小段说明、纯图形能力条）。
- 上传态：所有卡片以骨架方式排布，逐张按月相 loading 节奏点亮填充。
- 「下一步」按钮固定在右下悬浮，圆形，深灰。

## 3. 匹配页 `/match`

现状：一张卡说明 "暂无候选人画像" + 去建立画像按钮 + 返回。三个方向都保留"未建立画像时引导到 onboarding"这条空态跳转，只是视觉不同；有画像时展示匹配工作台。

### 方向 A — 双列画像连线（Dual Portrait + Bezier）

- 左列候选人画像（复用花瓣能力盘缩小版），右列岗位画像（岗位 JD 结构化字段块）。
- 中间实时 SVG 贝塞尔连线：绿色（match，深灰实线 1px）、红色（risk，深灰虚线 0.5px），hover 一根线时其他淡到 10%。
- 顶部横向 KPI 条：Overall / Skills / Culture / Risk 四个数值，用极小字号 + 大数字对比。
- 空态：中间放一颗描边圆 + 一行「先建立你的画像 →」文字链接。

### 方向 B — 单页滚动叙事（Scroll Narrative）

- 参考「fffunction studio radio」半透明表盘：整页背景是一颗巨大半透明表盘，随滚动旋转，指针指向当前解读段落。
- 内容分为 5 屏：Overview → Why Yes → Why No → Actions → Next Job。每屏一句大标题 + 极简数据。
- 匹配分数用月相圆展示（满月=100%，弦月=中等，新月=低）。
- 空态：整页只有一颗描边圆 + 「NO PROFILE YET / 建立画像」，圆随鼠标 parallax 移动。

### 方向 C — 决策仪表台（Decision Console）

- 三段式布局：左 2 栏候选人卡、中 6 栏匹配详情表、右 4 栏行动建议。
- 匹配详情表以 Swiss 网格呈现：每一行 = 一个维度，列包含 [维度名] [候选人值] [岗位要求] [Δ 差异图形化条] [W/I 标签]。
- 顶部通栏保留原 "动态岗位匹配工作台" 标题，右侧加当前岗位切换器（细线下拉）。
- 空态：整个仪表台以骨架线框呈现，中间叠一句「建立画像后此仪表台会点亮 →」。

## 4. 对比页 `/compare`

现状：登录弹窗 + 顶部提示"登录后可查看对比池"。三个方向都保留登录入口（不改逻辑），只改视觉与登录后的对比池呈现。

### 方向 A — 轨道比较池（Orbit Pool，refer.pdf 主推）

- 中心候选人画像大圆（花瓣能力盘），周围 3–5 条同心轨道，岗位以空心圆节点散布在轨道上。
- hover 岗位：其他轨道淡到 15%，中心与该岗位间生成贝塞尔连线，右侧滑出极简数据面板（Why Yes / Why No / Match %）。
- 底部横条控件：轨道数量、排序维度（薪资/匹配度/新旧）、显示密度。
- 登录门槛：未登录时轨道以幽灵态展示（更淡 + 静止），顶部一条极细 banner "登录后启动轨道"。

### 方向 B — Shift 网格对比（Shift Grid）

- 岗位以卡片按 Swiss 密排网格铺陈，每张卡上部是月相匹配度图 + 岗位名，下部是三条能力对比迷你条。
- 顶部 sticky 筛选：维度切换 tab（细线下划线态）。
- 选中两张卡时中间弹出「Δ 对比抽屉」，逐维度显示差异（← A 优 / B 优 →）。
- 登录弹窗改为顶部下拉的极细条（非模态遮罩），不阻断浏览。

### 方向 C — 双柱字体对撞（Type Duel）

- 参考 A24 "HOW THIS WORKS"：把两个正在对比的岗位标题放大到 200px 分列左右，中间一条竖线 0.5px 分隔。
- 下方逐条列出对比项（薪资 / 城市 / 团队 / 挑战 / 匹配点），左右两侧数据对齐到中线，差异方以深灰、劣势方以淡灰。
- 岗位选择改为顶部一条水平轨道（点选替换左/右主角）。
- 登录门槛：整个「岗位轨道」以毛玻璃盖住，浮出居中的编号目录式登录卡（复用首页方向 B 的字体语言）。

## 5. 投递页 `/delivery`（demo 当前 404，按需求文档语义补齐）

功能入口保留：查看/新增/修改投递项、状态标签流转、进入面试准备。

### 方向 A — 智能表格（Smart Table，refer.pdf 直接对标）

- 参考飞书多维表：分组行、状态标签、进度条、内嵌操作按钮，全部沿用 Swiss 极细边框（0.5px）。
- 状态标签色彩化程度极低：仅用深浅灰 + [W]/[I]/[✓]/[✕] 文字标记区分。
- 进度条改为月相刻度（新月→满月），5 档对应「投递/初筛/面试/Offer/入职」。
- 顶部工具条：视图切换（Table / Board / Timeline）、分组、筛选。

### 方向 B — 看板泳道（Board Lanes）

- 5 列泳道横向排布（投递 → 初筛 → 面试 → Offer → 入职）；卡片可拖拽，动效沿用「水左右倾倒」的缓入缓出。
- 卡片：岗位名（大字）+ 公司（小字）+ 匹配月相 + [W]/[I] 状态点。
- 顶部固定筛选/排序条与批量操作。
- 空泳道显示描边虚线框 + 一句 caption。

### 方向 C — 时间线书页（Timeline Journal）

- 参考编辑排版：整页是一份「求职日志」，按日期倒序，每条投递是一段带小标题的段落 + 右侧一条竖轨迹图。
- 每条投递的状态变更以极细横线打点在右侧竖轨上，hover 打点弹出小面板。
- 顶部提供「新增投递」入口（下划线文字链接），"筛选/排序"隐藏在右上角的圆形菜单按钮里。
- 适合阅读式复盘场景，密度较低但沉浸度高。

## 6. 组件与 Token 影响（技术侧，可跳过）

不管选哪 3 套组合，都会落地这套共享底座：

- `src/index.css`：新增 HSL token `--paper (#F1F1F1)`、`--ink (#404040)`、`--line (#D4D4D4)`、`--ink-strong (#0A0A0A)`；`--radius` 收敛为 0；新增 `--dur-slow: 600ms`、`--ease-swiss: cubic-bezier(.2,.7,.2,1)`。
- `tailwind.config.ts`：暴露上述 token；新增字体族 `display` / `sans` / `mono`；新增 `borderWidth: { hair: '0.5px' }`。
- 新组件：`DialNav`（半圆表盘导航）、`MoonLoader`（月相 loading）、`TiltLoader`（水倾倒 loading）、`PetalModel`（花瓣能力盘）、`OrbitPool`（轨道比较池）、`BezierConnector`（贝塞尔连线）、`SmartTable`、`BoardLane`、`EmptyState`（大字 + 圆点入口）。
- 所有现有 shadcn 组件仅新增 `variant="swiss"`，不删旧变体，保证渐进替换。

## 7. 建议的选择流程

**你只需要为每个页面选一个方向（A/B/C），共 5 次选择。** 全部收齐后我按以下顺序落地：

1. 阶段 0：共享底座（tokens + `DialNav` + `MoonLoader` + `EmptyState`）
2. 阶段 1：匹配页（P0，产品核心）
3. 阶段 2：对比页（P0，refer.pdf 明确指定）
4. 阶段 3：投递页
5. 阶段 4：画像页
6. 阶段 5：首页

每完成一个阶段，我会截图给你验收，通过再进入下一个。
