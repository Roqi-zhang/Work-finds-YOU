# 能力花微调（仅画像页 profile.html）

只改下面 5 点，其余（左侧文案、步骤、上传逻辑、跳转、4 个状态机、花瓣形状本身）完全不动。

## 1. 放大花朵、弱化花茎

- SVG viewBox 从 `190 200 400 720` 收紧到只包住花头（约 `195 205 330 400`），花在同样容器里显著变大。
- 花茎只保留花心下方一小截收尾（约 60px）与那片叶子，长茎与底部延伸段去掉。
- 线条更柔：`stroke-width` 略降、`stroke-linecap/linejoin: round`、描边透明度略降；花瓣坐标与 `spline()`/`shape()` 逻辑一个都不改，形态保持现状。

## 2. 8 片花瓣全部批注

- `drawNotes()` 去掉 `.slice(0, 3)`，8 个维度全部出批注。
- 排布改为按花瓣角度分左右两侧、沿角度排序后垂直分槽（左右各 4 条，间距固定），避免重叠；每条再加一点随机水平/垂直抖动与 ±2° 轻微旋转，保持手写的自由感。
- 文案格式沿用现在的：`维度短批注 4/5`（≤16 字），证据不足的显示「证据不足」不带分数。
- 箭头仍是手绘钩状曲线，指向各自花瓣中点。

## 3. LET YOUR FLOWER BLOOM 改花体

- 引入花体脚本字体（Google Fonts，`Parisienne` 或 `Mrs Saint Delafield`，接近图 1 的连笔签名感），仅用于 `.state-line`。
- 字号从 11px 提到约 34–38px，去掉全大写与字距 letter-spacing，保持小写连笔原样 `Let your flower bloom`，透明度略提。
- 只有 empty 态用花体大字；其余状态行（READY / ANALYSING / BLOOMED）继续用原来的小号大写体，避免破坏节奏。

## 4. 去掉两处多余元素

- 「建立画像」按钮右侧的提示文字（ready 态的 `hintLine`）置空。
- 简历卡片右下角的 `×` 移除按钮去掉（DOM + CSS + 事件一并删除）；移除简历改由重新点击卡片/重新上传覆盖。

## 5. 下方文字区改为 8 花瓣详细分析

替换现有「经验/技能/动机/风险」四张卡，改成按 PRD 7.4 的 8 个维度逐条展开，分三组（对应 7.4.1 的三类判断）：

```text
能不能做            能不能做成           能不能长期适配
专业技能 4/5        执行交付 5/5         学习适应 4/5
业务理解 3/5        沟通表达 3/5         动机匹配 —/5
问题分析 4/5        协作影响 2/5
```

每个维度一个条目，展示 5 项（全部来自 `AbilityPetal` 类型）：

- 标题行：`专业技能 SKILL` + 右侧分数 `4/5`
- 分数条：0.5px 细线刻度，5 格填充对应分数（证据不足为虚线空条）
- `EVIDENCE 证据`：简历中的原始依据，1 句
- `WHY 得分理由`：为什么是这个分，1 句
- `ACTION 优化动作`：可执行的下一步，1 句
- 证据强度标记：`[STRONG] / [MEDIUM] / [WEAK] / [MISSING]`，用文字标记而非颜色

数据直接复用现在 `result` 数组里已有的 `evidence / why / action / score` 字段，只是补上 `evidence_strength`，不新增业务逻辑。

## 技术说明

- 仅编辑 `public/previews/profile.html`（含其内联 style/script）；`_shared.css` 不动。
- 新字体通过已有的 Google Fonts `<link>` 追加参数引入。
- 仍是纯静态预览，无后端改动。
