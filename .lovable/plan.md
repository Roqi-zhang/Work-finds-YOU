### D1 展开：分级用模（控成本的核心）

| 任务 | 频次 | 推荐 | 理由 |
| --- | --- | --- | --- |
| 简历解析 | 每人 1–2 次 | 国产多模态模型（如 Qwen-VL / 豆包视觉版） | 读版式，便宜 |
| JD 解析 | 每岗位 1 次，量最大 | 国产轻量文本模型（如 DeepSeek / Qwen 中档） | 抽字段，极便宜 |
| 匹配分析 | 低频，决定口碑 | 国产旗舰推理模型（如 DeepSeek-R 系 / Qwen-Max） | 需要推理链与稳定结构化输出 |

要点：
- 模型名写成配置项（存数据库或环境变量），换模型不改代码。
- 你只需提供 1–2 个厂商的 API Key，我用密钥管理存到服务端，前端永远拿不到。
- 每次调用记录 token 与耗时，用于核算单用户成本，为定价提供依据。
- 兜底：主模型失败时自动切备用模型，避免单点。

**需要你提供**：选定 1–2 家厂商并拿到 API Key（我会在需要时通过安全表单向你索取，不要直接贴在聊天里）。

### D3 展开：分数如何算

模型只输出「证据条目」（每条含维度、正/负、强度、原文引用）。8 维分数由后端固定公式合成，公式与版本号一并入库。好处：同一份简历重复跑分数一致，用户申诉时可逐条追溯，调分只改公式不用重跑模型。

## 二、面向中国用户的两项前置事项（重要）

1. **访问速度与可达性**：当前托管在海外，中国大陆访问会明显变慢，部分网络下不稳定。若主力用户在大陆，中长期需要国内加速或国内节点部署。
2. **备案**：在中国大陆正式面向公众运营需要 ICP 备案，备案要求域名在境内主体名下并解析到境内服务器。

建议路径：先用自有域名 + 海外托管上线跑通产品与付费验证；确认要正式在国内运营时，再单独规划国内部署与备案。这一步不影响现在的开发。

## 三、实施计划

### 阶段 1 · 打地基
1. 开启 Lovable Cloud（数据库 / 认证 / 存储 / 服务端函数）。
2. 建表 + 行级隔离 + 授权：
   `profiles`、`resumes`、`user_profiles`（含 `version` / `is_current`）、`job_profiles`、`match_reports`（含 `stale` 标记与评分公式版本）、`compare_pool`、`applications`、`application_events`、`usage_counters`、`ai_call_logs`。
3. 接入登录：邮箱密码 + Google。未登录保留本地演示态，登录时一次性迁移本地数据。

### 阶段 2 · 前端迁移
4. 6 个 HTML 逐页迁成 React 路由页，视觉与交互 1:1 还原（花朵开花、月相、贝塞尔连线、折叠、状态下拉、对比池分环全部保留），`_shared.css` 的 Token 转为设计系统变量。
5. `_data.js` 这一层整体换成接口调用，页面组件不改。

### 阶段 3 · 接 AI
6. 三个服务端函数：`parse-resume`（多模态）、`parse-jd`、`run-match`（证据 → 规则算分 → 生成四段报告）。
7. 失败态与重试：状态机增加 `failed` / `queued`，前端可重试。
8. 长任务改为任务记录 + 轮询，避免超时。
9. 报告缓存：同一对（画像版本，岗位画像）唯一；画像换版时相关报告标记失效，进页面时按需重算而非全量重跑（控成本）。

### 阶段 4 · 运营化
10. 额度计数：游客 1 次画像试用；注册用户免费额度（1 次画像 + 3 次匹配）；超额提示升级。
11. 投递记录导出 CSV。
12. 自有域名接入（www 为主，根域跳转）。
13. AI 调用日志与错误监控，按用户核算成本。
14. 新功能弹窗公告组件（读一个 `announcements` 表，用户已读即不再弹）。

### 后续（不在本轮）
- 支付与会员分层。
- 国内加速 / 备案。

## 四、技术说明

- 后端：Lovable Cloud（Postgres + Auth + Storage + Edge Functions），扩容与备份由平台负责。
- 所有业务表按 `auth.uid()` 行级隔离并显式授权。
- 第三方模型 Key 存服务端密钥，仅在服务端函数内使用；模型 ID 走配置，可热切换。
- 结构化输出用 JSON Schema 约束，字段与前端插槽一一对应（decision / judgements[3] / steps[3] / dimension_scores[8] / sources[] / reasoning_trace）；解析失败时降级返回而非报错。
- 时间轴与统计由 `application_events` 推导。
- 账号删除：级联删除本人所有数据，简历原文件同步从存储移除。
