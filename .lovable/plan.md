# 能力花微调（仅 profile.html）

只改下面 4 点，其余（左侧文案、步骤、上传逻辑、跳转、4 个状态机、花瓣形状、下方 8 维度分析）完全不动。

## 1. 去掉花茎与叶子，只留花头

- 删除 `stemLeaf` 里那两条路径（长茎 + 叶片），花心下方不再有任何线条。
- 相应把 SVG `viewBox` 从 `150 195 410 420` 上移收紧到只包住花头，让花在同样容器里更居中、更大。

## 2. 按钮提示文字移到按钮下方

- `.stage-actions` 改为纵向排布：按钮一行，`hintLine` 提示单独一行放在按钮正下方（左对齐、上间距 10px）。
- 这同时解决第 4 点：bloomed 态的「hover 花瓣查看证据与得分理由」也会自动落到「进入匹配 →」按钮下方（两者是同一个元素）。

## 3. 花瓣批注：更淡、更小、箭头更手绘

- 文字：字号 19px → 13.5px（约 0.7 倍），颜色改为与「02 · CANDIDATE PROFILE」一致的淡灰（`var(--ink)` + opacity 0.45，即 caption 同款灰），去掉加深色。
- 箭头改成参考图那种自由手绘钩线：
  - 用三次贝塞尔（C）代替现在的单段二次曲线，两个控制点带各自的随机偏移，形成先甩出去再回勾的弧；
  - 起笔处按参考图加一个小「圈/钩」（半圆小环），线宽降到 0.7、opacity 0.35，`stroke-linecap: round`；
  - 箭头头部改为两笔不等长的短线（长 9 / 短 6，角度 0.4 / 0.6），不再是对称的等腰尖。
- 排布优化（解决「乱」）：
  - 左右各 4 条不变，但纵向槽位改为等距固定分配后再只加 ±6px 抖动（现在是 ±16px，容易和相邻行挤在一起）；
  - 文字锚点向外推 24px，远离花瓣轮廓，箭头因此更长、走向更清晰；
  - 箭头终点从「花瓣中心」改为「花瓣中心朝花心回收 25%」的点，避免多条箭头都堆在花瓣外缘。

## 4. 技术说明

- 仅编辑 `public/previews/profile.html`（内联 style + script），`_shared.css` 不动。
- 无新增依赖、无后端改动。
