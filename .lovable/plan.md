# 能力花重做：回滚 SVG 花，改为 1:1 参考图

范围：只改 `public/previews/profile.html` 的右侧舞台与左侧上传/按钮区。导航、下方 4 张画像卡片、跳转逻辑不动。

## 一、回滚

删除上一轮新增的全部 SVG 花逻辑：贝塞尔花瓣生成、花蕊、花茎叶、瓣尖标签、SVG 内批注、开花描边动效、花心上传圆。右侧舞台清空重来。

## 二、左侧（上传入口）

- 上传区移到左侧，位于步骤条下方：一个矩形虚线框，支持点击选择与拖拽上传（PDF / Word / 图片），沿用已有的文件校验与文件名省略号截断。
- 未上传时：只显示「← 返回」。
- 上传成功后：显示文件名 + 体积，并出现「建立画像」按钮（出现时带淡入上移动效）。
- 点击后按钮进入 loading 态「分析中」，约 2.6s 后完成。

## 三、右侧（花）

**未点击建立画像前，右侧完全静止不变：**

- 完整展示参考图那朵单线条花（原图 1:1，不转 SVG，不裁剪、不变形，居中，最大高度约 560px）。
- 花下方一行字：`LET YOUR FLOWER BLOOM`（全大写、字距 0.22em、10px、弱化透明度）。
- 无 hover、无 tooltip、无分数、无标签。

**点击建立画像 → 分析中：**

- 花整体降到低透明度并做极缓的呼吸；下方文字换成 `ANALYSING…` 配月相 loading。

**分析完成：**

- 花恢复实色，8 个能力维度以「手写批注」形式浮现在花的四周（不改花本身的形状）。
- 下方文字换成 `YOUR FLOWER HAS BLOOMED`。
- 批注按顺序 stagger 淡入，同时下方 4 张画像卡片（经验 / 技能 / 动机 / 风险）照旧渲染。

## 四、手写批注样式（参考图 1）

- 手写风字体栈（系统手写体 + cursive 回退），纯白/墨色单色，无底框。
- 每条批注 = 一行短文案（维度名 + 分数，如「执行交付 4/5」）+ 一根手绘感细弯箭头指向花的对应位置。
- 箭头为略带抖动的二次贝塞尔曲线 + 小箭头头部，0.5px 描边，画法与参考图一致（细、长、末端带钩）。
- 只标 3–4 条（最高分与差距最大的维度），其余维度留给下方卡片，避免画面拥挤。
- 批注绝对定位在花的容器上（左右各 2 条），不遮挡花本体。

## 技术说明

- 参考花图复制为 `public/previews/flower.jpg`（静态预览目录内直接引用，`<img>` 呈现）。原图为白底黑线：浅色模式直接用 `mix-blend-mode: multiply` 贴合米白背景；深色模式加 `filter: invert(1)` 保持线条为浅色。
- 批注层为覆盖在 `<img>` 上的一层绝对定位 SVG（仅画箭头）+ HTML 文本，坐标写死在花容器的相对百分比上，随容器缩放。
- 状态机：`empty` → `analysing` → `bloomed`，用 body/stage 上的 class 切换，无其他 JS 结构变化。
