# 花瓣透明度层级增强 · 单点优化计划

只做 1 个修改：让花瓣描边/整体透明度随 1–5 分呈现更明显的层级，从 10% 黑色到 85% 黑色。其余所有布局、文案、交互、其他页面完全不变。并保存当前可回滚的基线版本。

## 1. 保存当前基线（回滚点）

将当前 `public/previews/profile.html` 复制一份为 `public/previews/profile.html.baseline`。
这样后续任何修改都可以直接回滚到这一版本。

## 2. 修改花瓣透明度插值

当前代码片段（`.petal` 样式）：

```css
opacity: calc(.22 + var(--sd, .5) * .78);
```

目标：将范围调整为从 10% 到 85%，让低分更淡、高分更实，区分度更大。

```css
opacity: calc(0.10 + var(--sd, 0.5) * 0.75);
```

配合已有的 `--sd` 映射（null/证据不足 → 0.1；1 分 → 约 0.30；5 分 → 1.0），
实际透明度约 17% → 85%，_null 维度仍保留虚线样式不变。

## 3. 验证

在预览面板中确认：
- 1 分花瓣明显比 5 分花瓣淡；
- 5 分花瓣接近实心黑色但不刺眼；
- null 维度仍是虚线小瓣且最淡；
- 其他元素无可见变化。

## 不包含的修改

- 不调整花瓣长度、形状、开花动画；
- 不改动批注、按钮、弹窗、JOB PROFILE 页、导航；
- 不修改其他页面。
