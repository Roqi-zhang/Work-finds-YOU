# MATCH 页结构重构 · 四段式决策报告

保留页面最上方的匹配度大字（78% match 与月相刻度背景不变），其下方内容全部重写为固定的四段结构。这是全局模板：换用户、换 JD 只换内容，结构与顺序永远一致。

## 页面结构（从上到下）

```text
[ 保持不变 ]  匹配度大字 · 78% MATCH + 月相分数盘

01  一句话决策
02  三个关键判断
03  投前 3 步
--------------------------------  以上默认展示
04  证据展开（默认折叠，点击后展开）
```

### 01 一句话决策
一句结论 + 四个字段横排：
- 是否优先投：优先投 / 改完再投 / 可投不优先 / 不建议投
- 匹配分：0–100
- 胜算等级：高 / 中高 / 中 / 低
- 投递优先级：Top 1 / Top 3 / 备选 / 放弃

### 02 三个关键判断
三行，固定顺序：最大优势 → 最大缺口 → 最大风险。
每行：标题一句话 + 一行说明 + 关联花瓣标签（如「专业技能 / 执行交付」）。

### 03 投前 3 步
三行，固定顺序：
1. 简历要改什么
2. 作品集或项目表达要补什么
3. 面试或自我介绍要准备什么
每行为可执行动作，不写泛泛建议。

### 04 证据展开（默认折叠）
一条 0.5px 分隔线 + 「展开证据 ↓」触发。展开后包含四块：
- 详细证据：按 Conclusion / Evidence / Reasoning / Impact / Action 五段展示
- 分项评分：8 个能力维度，我的分 vs 岗位要求分
- 每个花瓣的推理：逐维度一句推理
- 外部岗位信息来源：来源列表（JD 原文 / 公司信息 / 同类岗位等）

## 设计原则（写进结构里）
- 先回答「该不该投」，再回答「怎么改」，最后才让用户相信「为什么」。
- 默认层信息量极少，详情层承载全部证据。
- 视觉沿用现有 Swiss Style：0.5px 细线分隔、全大写小字段标签、等宽字体数字、无彩色块、无 dashboard 图表。

## 实施范围
